# AcademicVault Phase 10 UI Redesign

Applied without replacing the existing application features:
- Premium dark mode by default, persisted locally.
- Light mode toggle via floating theme control.
- Purple/indigo + blue accent visual system.
- Glassmorphism cards, gradients, glow and modern feedback UI.
- New Feedback page at /feedback.
- Feedback is stored locally in `localStorage` under `academicvault_feedback_v1`.
- Floating Feedback shortcut is available globally.
- Existing Supabase/local-only data architecture is unchanged.
